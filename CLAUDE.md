# Fudget

Domain terms live in `CONTEXT.md`; use them in code, tests and UI copy.

## Deciding things with the user

- A question whose answers are a set of options (split method, display period, how shared income counts): build every option as a selector in the UI and pick a sensible default. Skip asking.
- A question of direction (what to build next, scope, hosting, data source): ask.
